static

Carica un file FXML e ne visualizza il contenuto nello stage specificato.

Questo metodo gestisce il "cambio pagina". Se lo stage ha già una scena impostata, viene sostituita solo la radice (Root) della scena per mantenere le dimensioni della finestra. Se non c'è una scena, ne viene creata una nuova.

Precondition
Il file FXML corrispondente al parametro 'name' deve esistere nel percorso delle risorse (relativo alla classe Main).
Postcondition
Il contenuto visualizzato nello stage viene aggiornato e il titolo della finestra modificato.
Parameters
stageLo Stage (finestra) su cui applicare il cambio di vista.
nameIl nome del file FXML da caricare (escluso l'estensione .fxml).
titleIl titolo da assegnare alla finestra dopo il caricamento.
Returns
L'oggetto FXMLLoader utilizzato per caricare la vista (utile per recuperare il controller associato).
