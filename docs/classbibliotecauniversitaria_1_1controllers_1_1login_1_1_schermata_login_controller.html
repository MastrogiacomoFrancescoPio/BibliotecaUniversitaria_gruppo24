Detailed Description

Controller per la schermata iniziale di selezione Login/Registrazione.

Questa classe è un'interfaccia di benvenuto. Il suo scopo principale è determinare se l'applicazione è al primo avvio e reindirizzare l'utente alla schermata di Registrazione o di Login.

◆ initialize()

void bibliotecauniversitaria.controllers.login.SchermataLoginController.initialize ( ) throws IOException

Inizializza il controller e determina lo stato dell'archivio utente.

  • controlla se esiste un archivio utente (UserArchive) salvato in precedenza.
  • imposta il flag nuovoAvvio a true se l'archivio non esiste.
  • aggiorna il testo del pulsante (button) in base allo stato: "REGISTRATI" se è il primo avvio, "LOGIN" altrimenti.
Exceptions
IOExceptionse si verifica un errore durante la verifica dell'archivio (non gestito internamente).

◆ onLoginButtonPressed()

void bibliotecauniversitaria.controllers.login.SchermataLoginController.onLoginButtonPressed ( )
protected

Gestisce il click sul pulsante "Login" / "Registrati".

Questo metodo viene chiamato al click del pulsante nell'interfaccia. Il cambio di interfaccia è condizionatodal flag nuovoAvvio:

  • True: reindirizza l'utente alla schermata di registrazione.
  • False: reindirizza l'utente alla schermata di login.
