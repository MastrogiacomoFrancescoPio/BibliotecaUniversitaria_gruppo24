Detailed Description

Classe per la gestione dell'archiviazione delle credenziali utente. Questa classe viene utilizzata per serializzare e deserializzare le informazioni di accesso (email e password hashata) su file. È utile per mantenere la persistenza dell'utente loggato o delle credenziali di amministratore locale.
