Detailed Description

Rappresenta un prestito di un libro a un utente. Questa classe collega un libro e un utente tramite i loro UUID e gestisce le date relative al periodo di prestito (inizio e restituzione prevista). Implementa Serializable con gestione personalizzata per le property JavaFX.
