◆ carica()

void bibliotecauniversitaria.utils.Configurazione.carica ( File configurazioneFile) throws IOException

Carica le impostazioni dal file specificato. Legge il file riga per riga. Le righe che iniziano con '#' vengono ignorate. Le righe contenenti '=' vengono splittate in chiave e valore e inserite nella mappa.

Precondition
Il file deve esistere ed essere leggibile.
Postcondition
La mappa 'valori' viene popolata con i dati letti.
Parameters
configurazioneFileIl file da cui leggere la configurazione.
Exceptions
IOExceptionSe si verificano errori di lettura (I/O).

◆ getNumero()

int bibliotecauniversitaria.utils.Configurazione.getNumero ( String chiave)

Recupera un valore numerico associato a una chiave. Tenta di convertire il valore stringa associato alla chiave in un intero. Se la conversione fallisce, mostra un Alert di errore all'utente.

Parameters
chiaveLa chiave di configurazione da cercare.
Returns
Il valore intero convertito. Restituisce 0 in caso di errore di formato o chiave inesistente.
