static

Invia una email formattata utilizzando un template HTML. Carica un file HTML dalle risorse, sostituisce i placeholder {chiave} con i valori forniti nella mappa e invia il messaggio.

Precondition
Il servizio email deve essere configurato (isConfigurato() == true).
Il file HTML specificato deve esistere nella cartella delle risorse "html/".
Parameters
mailL'indirizzo email del destinatario.
soggettoL'oggetto dell'email.
nomeDelHtmlIl nome del file template (senza estensione .html).
chiaviMappa contenente le coppie chiave-valore per le sostituzioni nel template.
Exceptions
MessagingExceptionSe si verifica un errore durante l'invio (es. credenziali errate).
