Detailed Description

Controller per l'interfaccia Menu. Questa classe gestisce i pulsanti e la navigazione dell'interfaccia Menu. Le sue funzionalità principali consistono nell'instradare l'utente verso le varie schermate di gestione (Libri, Utenti, Prestiti) o nella schermata di Logout/Login.
